## MAIN — Behavior Tree

몬스터의 대기·추적·공격 등 다양한 행동과 우선순위를 유연하게 구성할 수 있도록 Behavior Tree 실행 구조를 구현했습니다.

Selector, Sequence, Decorator, Action 등의 노드를 컴포넌트 형태로 구성하여 필요한 행동 노드를 생성하고 연결할 수 있도록 했습니다.

노드 실행 결과는 `SUCCESS`, `FAILED`, `RUN`으로 구분했습니다. `RUN` 상태에서는 실행 중인 자식 노드의 위치를 저장하여 다음 프레임에도 해당 행동을 이어서 실행하도록 구성했습니다.

### 구현 기능

- Selector·Sequence·Decorator·Action 노드 구성
- SUCCESS·FAILED·RUN 실행 결과 처리
- RUN 상태의 실행 위치 유지
- 조건에 따른 행동 선택과 우선순위 구성
- 행동 노드의 독립적인 생성과 연결
- 공통 행동 노드 재사용

## Behavior Tree Node Editor

ImGui와 ImGui Node Editor를 이용하여 Behavior Tree를 시각적으로 제작하고 편집할 수 있는 Node Editor를 구현했습니다.

GUI에서 노드를 생성하고 연결하거나 해제할 수 있으며, 노드의 실행 결과를 색상으로 표시하여 현재 실행 중인 행동과 트리의 진행 흐름을 확인할 수 있도록 했습니다.

완성된 트리 구조와 노드의 설정값은 JSON 형식으로 저장하고 다시 불러올 수 있도록 구성했습니다.

### 구현 기능

- 노드 생성 및 삭제
- 노드 연결 및 연결 해제
- 노드별 속성 편집
- 실행 결과에 따른 노드 색상 표시
- Behavior Tree JSON 저장 및 불러오기

## Behavior Tree 구조 개선

초기에는 몬스터의 행동 선택과 피격 상태를 모두 Behavior Tree에서 처리했습니다.

피격 종류마다 다른 애니메이션과 상태 전환이 추가되면서 관련 노드가 비대해졌고, 행동 선택과 피격 반응의 흐름을 하나의 트리에서 추적하기 어려운 문제가 발생했습니다.

이를 해결하기 위해 Behavior Tree는 행동 선택을 담당하고, FSM은 피격과 같이 명확한 상태 전환이 필요한 부분을 담당하도록 책임을 분리했습니다.

- **Behavior Tree** — 대기·추적·이동·공격 행동과 우선순위 결정
- **FSM** — 피격·다운·페이즈 전환·죽음 등의 상태와 애니메이션 전환

이를 통해 공격 행동과 피격 반응이 서로 복잡하게 얽히는 것을 줄이고, 상태 전환을 기능에 따라 구분할 수 있도록 했습니다.

## Blackboard와 Reactive 노드

초기에는 몬스터가 Behavior Tree에 명령을 전달할 때 Flag를 사용했습니다.

기능이 늘어나면서 Flag를 활성화하거나 해제하는 주체가 불분명해지고, 타겟과 목적지 같은 데이터가 특정 몬스터 노드에 종속되어 행동 노드를 재사용하기 어려워졌습니다.

여러 노드가 함께 사용하는 타겟 Handle, 목적지, 현재 상태 등의 데이터를 Blackboard로 분리하여 특정 몬스터 클래스에 대한 행동 노드의 의존성을 줄였습니다.

또한 일반 노드는 `RUN` 상태일 때 실행 중인 행동을 이어서 처리하기 때문에, 더 높은 우선순위의 조건이 발생해도 즉시 행동을 전환하기 어려웠습니다.

이를 보완하기 위해 `RUN` 상태에서도 이전 조건부터 다시 평가할 수 있는 Reactive 노드를 추가했습니다. 노드의 용도에 따라 기존 행동을 유지하거나 높은 우선순위의 행동으로 전환할 수 있도록 구성했습니다.

### 구조 개선

- 공용 데이터를 Blackboard로 분리
- 몬스터 클래스에 대한 행동 노드의 직접 의존성 감소
- Reactive 노드를 이용한 우선순위 재평가
- 상황에 따른 실행 유지와 행동 중단
- Subtree를 이용한 공통 패턴 재사용

## 애니메이션과 전투 연동

공격 애니메이션의 진행 비율에 맞춰 이동·공격 판정·사운드·이펙트가 실행되도록 Behavior Tree의 애니메이션 노드와 전투 기능을 연동했습니다.

각 기능이 지정된 애니메이션 구간에서 한 번만 실행되도록 상태를 관리하고, 애니메이션이 종료되면 다음 행동으로 전환하도록 구성했습니다.

### 구현 기능

- 애니메이션 진행 비율에 따른 이동량 적용
- 공격 판정 활성화
- 공격 사운드 재생
- 공격 및 피격 이펙트 생성
- 애니메이션 종료 판정
- 종료 후 다음 Behavior Tree 노드로 전환

## 몬스터·보스 적용

공통 Behavior Tree 구조를 기반으로 일반 몬스터와 보스의 행동을 구성했습니다.

일반 몬스터는 플레이어와의 거리와 현재 상태에 따라 대기·추적·공격 행동을 선택하도록 했습니다. 보스는 전용 조건과 공격 노드를 추가하여 개별 패턴과 페이즈를 구성했습니다.

### 적용 콘텐츠

- 거미 몬스터의 추적·공격 행동
- 트롤 몬스터의 근접 공격과 돌진 패턴
- 트롤 돌진 중 벽 충돌에 따른 행동 전환
- Pensieve Guardian 보스 공격 패턴
- Ranrok Dragon 보스 공격 및 페이즈 패턴
